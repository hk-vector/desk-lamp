# Modular Desk Lamp

This is a desk lamp concept I designed in **Blender** and then imported into **FreeCAD**.
The model is currently a digital design.

## What’s in the design?

- A circular base
- An arm and connector structure
- A lamp head
- Separate model files for viewing or further editing

## Tools I used

- **Blender** — to create the 3D model
- **FreeCAD** — to import the exported model and save the project

## Files

- `.glb` — the exported 3D model
- `.FCStd` — the FreeCAD project

## Notes

The file will not have editable sketches as it was created by importing an exported glb file from Blender into FreeCAD.
